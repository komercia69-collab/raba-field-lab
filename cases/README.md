# Cases

**Status:** public case area / non-canonical

This directory is for bounded case records that have explicit permission for public use.

A case should not be added merely because it was discussed with RABA or shared privately.

Before publication, confirm:

- publication permission;
- anonymization/confidentiality requirements;
- frozen baseline or equivalent pre-analysis record;
- bounded research question;
- evidence limits;
- explicit status as non-canonical unless separately authorized otherwise.

Recommended public case view:

1. **Before** — what was known or operating before the interaction.
2. **Boundary question** — what was actually being tested.
3. **Interaction** — what comparison, review, or experiment occurred.
4. **After** — what changed in understanding, process, or artifact.
5. **What did not change** — preserved boundaries or unchanged facts.
6. **Remaining uncertainty** — unresolved questions or insufficient evidence.
7. **RABA status** — whether the result is only an external research result, a research delta candidate, or something else explicitly decided later.

An `After` state is not assumed to be better. Null, negative, falsifying, or externally stronger outcomes are valid.
