## Multi-Agent Systems

### [When Every Agent Does Its Job — and the System Still Gets the Meaning Wrong]({{ "/multi-agent-meaning-drift-worked-case.html" | relative_url }})

A synthetic failure test of a Chief + specialist multi-agent workflow.

The case asks whether a system can preserve files, evidence, ownership, handoffs, and human approval while still carrying a subtly changed interpretation of the original human condition through the whole workflow.

**Current result:** `FAILURE POSSIBLE / SIMPLE CORRECTION PARTLY ABSORBS IT / NARROWER QUESTION REMAINS`

**Course:** `REUSE / REFINE / CONTINUE NARROW TEST`

**Status:** synthetic worked case / working research record / non-canonical

## Case boundary

A public case should be treated as a bounded research record, not as proof of a general RABA claim.

Where a case is synthetic, that must be stated explicitly.

Where a case uses external material, evidence limits and verification boundaries should remain visible.

Where an existing approach absorbs the problem, `REUSE / STOP` or refinement is a valid result.
